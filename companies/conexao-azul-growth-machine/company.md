# Conexão Azul Growth Machine

## Missão
Gerar R$40.000 em novas vendas em 60 dias usando IA, automação, CRM multicanal, Odoo, Chatwoot, n8n, OpenClaw, Claude Code e equipe humana enxuta.

## MTP (Massive Transformative Purpose)
Tornar PMEs capazes de operar com inteligência, automação e escala de grandes empresas, sem perder o atendimento humano.

## Princípios Operacionais
- IA como alavanca, humano no controle
- Automação antes de contratação
- Dados antes de opinião
- Cada entrega vira case
- Cada objeção vira melhoria de oferta
- Cada processo repetitivo vira automação
- Cada tarefa tem dono, prazo e KPI

## Stack Tecnológico
| Sistema | Papel |
|---------|-------|
| Paperclip | Control plane: organograma, metas, governança, ROI |
| Hermes | Agente comercial, pipeline, follow-up |
| OpenClaw | Executor técnico/operacional |
| Claude Code | Engenharia cuidadosa e produção |
| Codex | Scripts, auditorias, SQL read-only |
| n8n | Barramento de automações |
| Odoo | CRM, financeiro, propostas, funil |
| Chatwoot | Atendimento multicanal, WhatsApp |
| Humanos | Aprovação, relacionamento, venda, decisões críticas |

## Equipe (4 colaboradores/sócios)
1. CEO/Growth Lead — fechamento, relacionamento, priorização
2. Comercial/CS Lead — pipeline, follow-up, CRM, cliente
3. Tech Lead — arquitetura, escopo, aprovação produção
4. Marketing/Ops Lead — conteúdo, cases, cadência

## Regra de Ouro
Agentes preparam, humanos aprovam ações externas e decisões críticas.
